艺息 ArtBreeze 隐私说明

更新日期：2026-10-28 · 版本 1.2.2

ArtBreeze 在清单列出的 AI 网页识别 Enter、发送按钮和表单提交操作，用于展示画作。仅在本地检查站点域名、必要路径和控件属性以限制触发范围；不记录或外发完整聊天地址或对话 ID。它不读取或保存输入框中的聊天正文、模型回复、账号资料或浏览历史，也不代替用户向 AI 发送消息。

数据与保存位置

启用、外观、宽度、时长等偏好保存在 Chrome storage.sync；用户启用 Chrome 同步时，这些偏好可经浏览器账号同步。

当前作品和场景、最近阅读、收藏、滚动位置及有限的图片缓存保存在当前浏览器配置的 storage.local。当前标签的阅读恢复点可保存在 storage.session，关闭该标签或浏览器后失效。

收藏和最近记录只描述在本扩展中展示的作品及其公开来源，不记录用户的 AI 对话地址。未向开发者服务器上传，也未用于广告或遥测。

24 张展厅图片及配色、挂画区域随安装包提供，匹配和照明在本地执行。

外部请求

作品列表来自 www.gstatic.com；作品图片来自 lh3.ggpht.com、lh3.googleusercontent.com，备用图片来自 Wikimedia Commons 的 upload.wikimedia.org。内容提供方可收到 IP、所请求的公开资源和普通网络信息。扩展请求省略凭证及网页 Referrer，不携带聊天、账号、收藏或对话标识。不会下载或执行远程 JavaScript/WASM。

用户主动点击来源链接时，浏览器访问该网站，网站适用其自身隐私政策。

控制与删除

仅申请 storage API 权限；网页注入与内容来源通过清单中的具体站点范围限定，不要求历史记录、剪贴板、全站访问或 activeTab。可随时禁用展示或关闭入口。

完整设置中的“清除本地数据”删除本扩展的收藏、最近阅读、恢复点及缓存，保留同步偏好。同步偏好的保留/移除由 Chrome 同步设置管理。卸载移除本扩展的本地数据。

上述数据仅用于本扩展已说明的展示、设置和阅读管理功能，遵守 Chrome Web Store 用户数据政策（包括 Limited Use 要求）。不出售数据，不用于广告或其他无关用途；开发者不会收到或人工读取保存在用户设备上的阅读记录。
